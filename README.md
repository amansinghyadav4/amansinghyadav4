## 🧠 ModelRoute

### `AI Task Analyzer & Model Routing Extension`

**TypeScript · React · Chrome Extensions · FastAPI · Python · Claude · Gemini**

<div align="center">

<img src="https://img.shields.io/badge/STATUS-ACTIVE-2ea043?style=for-the-badge&labelColor=161b22"/>
<img src="https://img.shields.io/badge/AI_PLATFORMS-3-58a6ff?style=for-the-badge&labelColor=161b22"/>
<img src="https://img.shields.io/badge/TASK_CATEGORIES-10%2B-8957e5?style=for-the-badge&labelColor=161b22"/>

</div>

<br/>

A privacy-first Chrome extension that analyzes user prompts across **ChatGPT, Claude and Gemini**, then recommends suitable AI models based on task requirements.

<details>
<summary><b>▸ Architecture</b></summary>

<br/>

```text
                    USER PROMPT
                         │
                         ▼
                 ┌───────────────┐
                 │ TASK ANALYZER │
                 └───────┬───────┘
                         │
                         ▼
                ┌─────────────────┐
                │ CATEGORY ENGINE │
                └────────┬────────┘
                         │
                         ▼
                 MODEL RECOMMENDER
                    │    │    │
                    ▼    ▼    ▼
                 Claude Gemini ChatGPT
```

</details>

<details>
<summary><b>▸ Engineering Highlights</b></summary>

<br/>

* Analyzes tasks across **10+ categories**
* Resilient provider adapters
* Ranked DOM selectors
* Fallback provider detection
* Runtime health telemetry
* Service-worker lifecycle recovery
* Client-side session/local storage isolation
* Fail-closed permissions
* Safeguards against unintended prompt persistence or transmission

**Engineering theme:** `Privacy × Reliability × AI Routing`

</details>
